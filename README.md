# Kcal

Personal calorie tracker, companion to [lifts](https://github.com/computer347/lifts). One static page, no build, no backend.

- **Photo / Describe** – Gemini (your own API key, stored only on the phone) estimates items, grams and macros; you edit before saving. Reads nutrition labels too.
- **Scan** – barcode → Open Food Facts; unknown codes fall back to photographing the label, then stick to that barcode.
- **Search** – bundled Fineli (THL Finnish food composition data) + your own foods + Open Food Facts (Finland first, worldwide on request).
- **Targets** – Mifflin-St Jeor + activity + Lifts workout kcal on gym days; adaptive expenditure from intake vs weight trend once there are two weeks of data.
- **Lifts bridge** – when both apps are served from the same site, this app reads (never writes) the Lifts weigh-ins and session kcal from shared browser storage.

## Deploy

Push to GitHub, enable Pages on the repo, add the site to the home screen from Safari. Keep it on the same GitHub Pages user site as lifts (e.g. `computer347.github.io/Calorie-Counter/`) so the shared storage works.

## Files

- `index.html` – the whole app. `manifest.json`, `icon-*.png` – PWA bits (`node tools/icon.mjs` regenerates icons).
- `fineli.json` – generated by `node tools/fineli.mjs data/fineli_rel18 > fineli.json`. `data/` is git-ignored; Release 18 CSVs came from the mafredri/fineli-sql mirror on GitHub. To update, download a newer open-data release from fineli.fi into `data/` and rerun.
- `tools/test.mjs` – logic checks. `tools/smoke.mjs` – headless-browser UI run (serve the folder first).
